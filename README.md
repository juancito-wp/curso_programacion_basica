# Curso de recuperacion JavaScript

Este proyecto contiene ejercicios introductorios y el juego multijugador Mokepon.

## Ejecutar Mokepon

1. Entra a la carpeta `mokepon`.
2. Instala las dependencias con `npm install`.
3. Inicia el servidor con `npm start`.
4. Abre `http://localhost:8080` en el navegador.

Para jugar en multijugador, abre la direccion del servidor en dos ventanas o
dispositivos conectados a la misma red. En cada partida, elige una mascota,
muévete por el mapa con las flechas o los controles en pantalla y choca con el
otro jugador para comenzar el combate.
